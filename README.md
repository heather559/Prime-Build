# Prime-Build

Native, per-platform builds of the Heather Domi | Buyer Search app. Each platform folder is fully isolated — its own project, its own build files, no shared code — to avoid cross-contamination between builds.

- `mac/` — native macOS app (SwiftUI, Swift Package). Start here: see `mac/README.md`.
- `ios/` — not started.
- `android/` — not started.
- `windows/` — not started.
